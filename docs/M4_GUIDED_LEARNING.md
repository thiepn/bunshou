Baseline accepted M3 5630c9412a56dba1e38ec45d6e65616994641b04. Existing study screen already supports flashcards, listening, particle cloze and scramble; grammar handbook has explanations/comparisons and dialogue comprehension. New integrated pathway uses these source authorities rather than replacing them.
Each of 20 units: explanation, authored two-choice rule check with corrective explanation, existing dialogue comprehension, two listening choices and two typed production model comparisons. Adaptive selection prioritizes existing leeches, again/hard and due records, then unseen; no invented learner model. Honest listening credit needs completed TTS with Japanese voice and no transcript; assisted reading fallback. Production accepts exact normalized original script or corpus reading, no general linguistic judgement. First-pass and current results are session-only; missed and assisted tasks may be retried. Completed session logging deliberately uses existing practiceCount callback once per explicit session; no SRS, mastery, dialogue or unit-completion claims, backup/state schema unchanged. Coverage uses existing SRS classifications. All units selectable; no artificial prerequisites. Home/grammar direct entry plus responsive Guided nav. Existing StudyView, corpus, SRS, linguistics, SDK, storage/sync and interop module files unchanged. No production changes.
Limitations: unrecorded session scores and navigation are temporary, cannot resume precisely after reload or owner remount. Browser TTS depends on available Japanese voices; test stubs verify behavior not sound fidelity. Model comparison is not an unrestricted translation grader. This first M4 increment adds guided practice across the entire corpus by selection, not new 620 individually authored exercises. No change to original learning data and no claim of mastery.
